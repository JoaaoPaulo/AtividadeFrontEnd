# Atividades de Front-End

Exercícios e trabalhos da disciplina de Programação Front-End: HTML, CSS, JavaScript, Bootstrap e DaisyUI (Tailwind).

## Como abrir

Não há build nem dependências. Basta abrir o arquivo `.html` desejado no navegador. As bibliotecas (Bootstrap, DaisyUI, Tailwind) são carregadas por CDN.

### `RESPOSTAS/` — Respostas das provas práticas, por dia

Cada dia tem quatro questões sobre uma página da **Copa do Mundo 2026**, evoluindo de HTML puro até manipulação do DOM com JavaScript:

| Arquivo | Questão |
| --- | --- |
| `questao_01.html` | Estrutura da página em HTML |
| `questao_02.html` + `questao_02.css` | Estilização com CSS |
| `questao_03.html` + `questao_03.js` | Interação com JavaScript (ex.: exibir a tabela de jogos ao clicar) |
| `questao_04_script.js` | Manipulação do DOM (ex.: revelar e preencher o card de um jogador) |

- `DIA 1/` — Informações sobre a Copa do Mundo
- `DIA 2/` — Grupos e fatos da Copa do Mundo 2026
- `DIA 3/` — Informações sobre a Copa do Mundo (outra versão da prova)
